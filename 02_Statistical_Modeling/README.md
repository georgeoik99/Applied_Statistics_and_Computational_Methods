# Statistical Modeling

This directory contains applied statistical-modeling projects developed primarily in **R**, with Python used where it offers a clearer computational workflow.

The projects combine model fitting with statistical interpretation and may cover:

- linear and generalized linear models;
- logistic, Poisson, negative-binomial, Gamma, and related regression models;
- ANOVA and likelihood-based inference;
- coefficient estimates, standard errors, confidence intervals, and hypothesis tests;
- residual analysis, goodness of fit, and model diagnostics;
- model comparison and selection using measures such as AIC and BIC;
- prediction, classification, and uncertainty assessment.

## Projects

| Project | Methods | Language |
|---|---|---|
| `01_Zombie_Apocalypse_Logistic_Regression/` | Logistic regression, odds ratios, likelihood-ratio testing, classification metrics, and diagnostics | R / Quarto |
| `02_Multiple_Linear_Regression_Model_Selection/` | Multiple regression, VIF, AIC/BIC stepwise selection, coefficient inference, prediction intervals, and diagnostics | R / Quarto |

Additional MSc coursework and extended case studies will be added as the relevant material is reviewed.

## Organization

Each project is self-contained and includes its own README, analysis document, data or data-source instructions, dependencies, statistical interpretation, and limitations. Quarto is used as the common presentation system so that R and Python projects can share a consistent portfolio-friendly format without mixing languages unnecessarily within the same analysis.
